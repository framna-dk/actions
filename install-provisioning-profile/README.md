## [install-provisioning-profile](https://github.com/framna-dk/actions/blob/main/install-provisioning-profile/action.yml)

Installs a provisioning profile.

```yml
- name: Install Provisioning Profile
  uses: framna-dk/actions/install-provisioning-profile@v1
  with:
    op-reference: op://My Vault/My Provisioning Profile/profile.mobileprovision
```
